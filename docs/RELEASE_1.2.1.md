# GearPilot 1.2.1

## Behoben
- **Fehlermeldung beim Anklicken von Zielen** („secret string value … tainted by GearPilotPro“): Der Forever-Client gibt manche Werte eines Ziels in bestimmten Situationen nur noch verschlüsselt heraus. GearPilot prüft das jetzt und lässt den Wunschlisten-Hinweis dann einfach aus. Der Hinweis läuft außerdem erst nach dem Klick, nicht mehr mitten im Code des Spiels.
- `/gpp ep`: Quests ohne Gold zeigen kein „Gold 0“ mehr.
- Die Kartenteile aller Zonen sind jetzt im Paket („Ganze Karte“ im Kartenfenster).
